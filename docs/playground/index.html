この文書は署名済みです。1文字でも改変すると、検証結果が即座に変化します。ほかの例文は文書欄のメニューから選択できます。

検証と署名はブラウザ内で処理し、文書は送信しません。鍵や撤回リストを照会すると、照会先に検証の事実が伝わります。文書が指定する未知のホストには、許可を得てから接続します。

    リソース

    署名には画像などのファイルをハッシュ値で固定できます。このページはディスクを参照できないため、照合するファイルを添付するか、このパネルへドロップしてください。添付ファイルはこのタブ内でのみ使用します。

      TSA ルート証明書

      タイムスタンプの検証には、同梱する公開 TSA のルート証明書を使用します。ほかの TSA のトークンを検証する場合は、そのルート証明書（PEM または DER）を追加してください。追加した証明書はこのタブ内でのみ使用し、再読み込みで消去されます。追加した証明書に連鎖する TSA の時刻は検証済みとして表示されるため、入手元を確認した証明書だけを追加してください。

        検証サーバ

        mdsig serve などの検証サーバに同じ文書を送信し、その判定をこのページの判定と並べて表示します。サーバは OS のトラストストアを使用でき、CORS の制約も受けません。文書の全文がそのサーバに送信されるため、自身で管理するサーバを指定してください。指定は再読み込みで解除されます。

        連署の追加

        このブラウザはパスキー（WebAuthn）に未対応のため、パスキー方式は選択できません。

        このサイト（）用のパスキーは未登録です。「署名鍵の作成」タブで方式に「パスキー」を選択し、登録してください。

        秘密鍵とパスフレーズはこのページのメモリ内でのみ処理し、保存も送信もしません。署名の完了後は、失敗した場合も含めて破棄します。

          OpenPGP 鍵はこのページでは生成しません。gpg などの OpenPGP 実装で作成し、公開鍵を keys.openpgp.org または自ドメインの WKD で公開します。署名には「署名の追加」タブで秘密鍵を読み込むか、mdsig CLI を使用します（CLI は gpg を経由するため、スマートカード上の鍵も使用可能）。
          
                                    
          
                                        
          1. 鍵の生成
          
                                        
          gpg --quick-gen-key "Your Name <you@example.com>" ed25519 sign,cert
          
                                        
                                    
          
                                    
          
                                        
          2. keys.openpgp.org への登録 （表示される URL から確認メールを送信し、承認後にユーザ ID が配布されます）
          
                                        
          gpg --export you@example.com | curl -T - https://keys.openpgp.org
          
                                        
                                    
          
                                    
          ブラウザから登録する場合： keys.openpgp.org/upload
          
                                    
          
                                        
          3. WKD での公開 （任意。ドメインの管理者向け）
          
                                        
          gpg --with-wkd-hash --list-keys you@example.com
gpg --export you@example.com > .well-known/openpgpkey/hu/<hash>
          
                                        
                                    
          
                                    
          1行目の出力で、メールアドレスの前にある32文字が <hash> です。同じディレクトリに空の policy ファイルも配置し、ブラウザから取得できるよう Access-Control-Allow-Origin: * を付与します。
          
                                    
          
                                        
          4. CLI での署名 （gpg の既定の鍵を使用）
          
                                        
          mdsig sign file.md -m pgp
