          PGP 鍵はこのページでは生成しません。gpg などの OpenPGP 実装で作成し、公開鍵を keys.openpgp.org または自ドメインの WKD で公開します。署名には「署名の追加」タブで秘密鍵を読み込むか、mdsig CLI を使用します（CLI は gpg を経由するため、スマートカード上の鍵も使用可能）。
          
                  
          
                      
          1. 鍵の生成
          
                      
          gpg --quick-gen-key "Your Name <you@example.com>" ed25519 sign,cert
          
                      
                  
          
                  
          
                      
          2. keys.openpgp.org への登録 （表示される URL から確認メールを送信し、承認するとユーザ ID が配布されます）
          
                      
          gpg --export you@example.com | curl -T - https://keys.openpgp.org
          
                      
                  
          
                  
          ブラウザから登録する場合： keys.openpgp.org/upload
          
                  
          
                      
          3. WKD での公開 （任意。ドメインの管理者向け）
          
                      
          gpg --with-wkd-hash --list-keys you@example.com
gpg --export you@example.com > .well-known/openpgpkey/hu/<hash>
          
                      
                  
          
                  
          1行目の出力にある、メールアドレスの前の32文字が <hash> です。同じディレクトリに空の policy ファイルも配置し、ブラウザから取得できるよう Access-Control-Allow-Origin: * を付与します。
          
                  
          
                      
          4. CLI での署名 （gpg の既定の鍵を使用）
          
                      
          mdsig sign file.md -m pgp
